{% load i18n %} {% comment %}LV-72: the traceability block, shaped like SIGO's -- the screen operators already read every day with the DGAC. Copying that shape removes the mental translation between the authority's screen and this one, and "who did what, in what capacity, when, in what order" is how an auditor reads evidence. Shared by the flight permit, the geo plan and the aircraft's insurance filing (LV-81). Expects: - `steps` : [{code, label, state}] from the model -- `record.status_steps` for a StatusFlowMixin record, or a named flow like `aircraft.insurance_steps`. **Never a literal list written here**, which is the R1.1 trap. - `history` : its status history, oldest first, with the actor's groups prefetched by the view (unprefetched it is one query per row) - `history_title` : optional, already-translated heading for the table. The insurance filing is not a "request", so it says "Filing history" there instead. - `embedded` : optional. Drops the outer card and steps the headings down one level, so this can sit inside a section that already has a card and a title (the insurance block on the aircraft fiche) instead of nesting a card inside a card. {% endcomment %}
